# EB3A Ватты

Виджет Android для Bluetti **EB3A2247002180751**. По Bluetooth читает станцию и показывает, сколько ватт уходит в нагрузку прямо сейчас: выход AC + выход DC.

Приложение только читает регистры. Розетки и заряд оно не переключает.

## Установка готового APK

1. Скачайте `eb3a-widget.apk` на телефон.
2. Откройте файл и разрешите установку из этого источника.
3. Запустите «EB3A Ватты», включите Bluetooth, разрешите уведомления и поиск устройств.
4. Станция с этим серийным номером подставится сама, если она включена и рядом. Иначе выберите её в списке или введите MAC.
5. Нажмите «Не усыплять приложение», иначе Android оборвёт связь через несколько минут.
6. Домашний экран → удерживайте палец → Виджеты → **EB3A**.

Доступно пять виджетов (Виджеты → **EB3A**):

| Виджет | Размер | Что показывает |
|---|---|---|
| EB3A · Карточка | 3×2 | нагрузка, AC/DC, заряд |
| EB3A · Ватты | 2×1 | ватты и процент батареи |
| EB3A · Кольцо | 2×2 | батарея кольцом, нагрузка в центре |
| EB3A · Полоса | 4×1 | нагрузка, AC, DC, батарея в строку |
| EB3A · Потоки | 4×2 | полоски AC, DC, заряда и батареи |

Прозрачность фона всех виджетов настраивается слайдером в приложении.

Крупная цифра на виджете — текущая нагрузка в ваттах. Ниже отдельно AC и DC. Процент — заряд батареи.

Нужен Android 8 или новее.

## Сборка без Android Studio

Залейте содержимое этой папки в пустой репозиторий GitHub (ветка `main`) и откройте Actions → **Build APK** → Run workflow. Готовый файл будет во вкладке Artifacts.

Либо, если Gradle уже стоит локально: `./gradlew assembleRelease`. APK появится в `app/build/outputs/apk/release/`.
